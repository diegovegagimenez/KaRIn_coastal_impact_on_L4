# KaRIn_coastal_impact_on_L4

Code accompanying the manuscript on the impact of SWOT KaRIn observations on
delayed-time Level-4 (L4) sea level products along European coasts, assessed
against tide gauges (submitted to *Ocean Science*).

The repository contains the processing pipeline and the analysis and figure
scripts used in the paper. It does **not** contain any data (see
[Data](#data)) and no results, which are regenerated by the scripts.

## What is compared

| Label | Product |
|---|---|
| **MY** | Nadir-only multi-year DUACS L4 product (Copernicus Marine Service) |
| **MIOST-K** | Experimental MIOST L4 product that merges nadir altimetry with SWOT KaRIn observations (AVISO+) |
| **L3** | SWOT L3 KaRIn low-rate SSH, *Expert* product v3.0 (AVISO+) |

Both L4 fields are compared with daily, detided and DAC-corrected tide gauge
records at extraction radii of 10-100 km (median of the grid cells within the
radius), over the SWOT CalVal (1-day repeat) and Science (21-day repeat) phases.

## Setup

```bash
conda env create -f environment.yml
conda activate karin-l4
export KARIN_PROJECT_DIR=/path/to/working/directory      # see layout below
export KARIN_IHO_SHP=/path/to/World_Seas_IHO_v2.shp      # optional
```

Expected layout of `KARIN_PROJECT_DIR` (the folder names are those used by the
scripts):

```
$KARIN_PROJECT_DIR/
  data/raw/swot_l3_expert/       SWOT_L3_LR_SSH_Expert_*_v3.0.nc
  data/raw/miost_l4/             MIOST L4 daily files
  data/raw/duacs_l4_my/          MY, European Seas, 0.0625 deg
  data/raw/dac_l4/               Dynamic Atmospheric Correction
  data/processed_NRT/tide_gauges_nrt/   one .pkl per station
  PIPELINE_FINAL_LIMPIO/         outputs of pipeline/P1 and P2 (created by the pipeline)
```

No credentials are stored in the code. If you download AVISO+ data with your
own scripts, keep the credentials outside the repository.

## Workflow

1. **Pipeline** (`pipeline/`)
   * `P1_altimetry_tidegauge_processing.py`: extraction of the altimetry within
     each radius, detiding (UTide), DAC correction, 15-day LOESS and per-station
     metrics (RMSD, correlation). One run per extraction radius, for the
     extended window that excludes the near-real-time segment:
     ```bash
     python pipeline/P1_altimetry_tidegauge_processing.py --fixed-radius-km 50 \
            --skip-per-station --skip-per-region \
            --science-end 2025-07-06 --operational-window
     ```
     Repeat with `--fixed-radius-km R` for R = 10, 20, ..., 100 (`--from-csv`
     re-emits the metrics from the radius sweep without re-extracting).
   * `P2_advanced_value_added_analysis.py`: value-added analysis; here it is
     used for the per-station distance to the SWOT swath
     (`swot_proximity_by_station.csv`). Set `P2_FIXED_RADIUS_KM` to the same
     value as `--fixed-radius-km`.
2. **Analysis scripts** (`scripts/`, run from that directory, in this order)

| Script | Purpose | Main output |
|---|---|---|
| `final_v1_scale.py` | near/far-swath sweep over radii; regional medians | `final_v1_scale.json` |
| `verify_v3_numbers.py` | per-station table with number of grid cells | `per_station_radius_with_pixels.csv` |
| `regions_v2.py` | regionalisation, including the North Sea-Baltic transition zone | `station_regions_v2.csv` |
| `final_v3_regions.py` | all regional, near/far and paired-scale statistics | `per_station_radius_with_pixels_v2.csv`, `v3_*.csv` |
| `tidal_regime_proxy.py` | tidal regime of each station | `tidal_regime_proxy.csv` |
| `tidal_class_stats.py` | improvement by tidal class | printed |
| `compute_temporal_std_R50.py` | temporal variability of each product | `temporal_std_products_R50.csv` |
| `station_level_stats.py` | largest changes and correlation change | printed |
| `karin_coverage_all_stations.py` | valid KaRIn pixels within 50 km of each station | `results/l3_near_swath_scale/karin_coverage_*.csv` |
| `l3_near_swath_scale.py` | L3 extraction and tide gauge/L4 caches | `results/l3_near_swath_scale/*.pkl` |
| `l3_near_swath_scale_qc.py` | L3 vs L4 using default filtered SSH and `quality_flag == 0` | `results/l3_near_swath_scale/*_qc*.csv` |
| `l3_instantaneous.py` | instantaneous L3 vs tide gauge comparison | `results/l3_near_swath_scale/l3_instantaneous_*.csv` |

3. **Figures** (`scripts/make_fig*.py`, written to `figures/`)

| Script | Figure |
|---|---|
| `make_fig01_study_area_v2.py` | study area and regional classification |
| `make_fig07b_restyled.py` | RMSD maps of MY, MIOST-K and their difference |
| `make_figF_proximity_boxplot_v2.py [R]` | near/far-swath improvement by region at radius R |
| `make_figD_timeseries_example_v2.py` | time series at three near-swath stations |
| `make_figE_nearfar_bootstrap.py` | improvement vs extraction radius with bootstrap CI |
| `make_figN_l3_over_l4_pass16_qc.py` | L3 over MY and MIOST-K, western Mediterranean |
| `make_figO_l3_over_l4_transition_zone.py [YYYYMMDD]` | L3 over MY and MIOST-K, transition zone |
| `make_fig07c_corr.py` | correlation maps (supplement) |
| `make_fig07d_std.py` | temporal variability maps (supplement) |

## Notes

* Metric sign convention: `dRMSD = RMSD_MY - RMSD_MIOST-K` and
  `PI_RMSD = 100 * dRMSD / RMSD_MY`; positive values mean that MIOST-K is closer
  to the tide gauge.
* The "near-swath" group is formed by the stations located within 2 km of the
  footprint of the KaRIn swath of the CalVal passes (1, 3, 14 and 16).
* The scripts were developed in a working directory with the layout above; paths
  are read from `KARIN_PROJECT_DIR`.
